# Rock v0.7.3

Rock v0.7.3 adds pinned GitHub dependencies, array and slice rest patterns,
and more ways to express conversions and generic types.

## Highlights

- **Dependencies.** Rock packages can depend on GitHub repositories pinned to
  an exact commit. The build reuses verified checkouts and refreshes changed
  checkouts without replacing the path another build is already using.
- **Patterns and copying.** Destructure arrays and slices with rest patterns.
  Arrays are `Copy` when their elements are `Copy`. Structs and enums require
  an explicit `impl Copy`, and cannot implement it if a field is not `Copy`
  or the type implements `Drop`.
- **Generics.** Const parameters can have defaults. Function signatures and
  implementation headers can refer to associated types as `T::Assoc` when a
  bound provides the associated type. Trait-qualified calls can use argument
  and result types to select an implementation.
- **Standard library.** New string and character helpers cover searching,
  splitting, trimming, editing, and parsing. `TryFrom` and `TryInto` provide
  fallible conversions, including parsing `&Str` into `I64`.
- **Editor support.** The language server can show inferred types for
  unannotated local bindings and tracks diagnostics separately for each
  package target.

## Upgrading from v0.7.2

- Rebuild `.rkca` dependencies with the new compiler and its matching standard
  library. The artifact format changed.
- In `f(x).method!`, the method applies to the call result. In
  `f (x).method!`, it applies to the argument. Use `(f x).method!` to apply
  a method to the result of a spaced call.

## Install or update

The packaged toolchain targets Linux x86-64 GNU and requires glibc 2.39 or
newer, a C linker, curl, CA certificates, GNU tar, gzip, and `sha256sum`.
On Ubuntu 24.04, install `build-essential curl ca-certificates`. LLVM 18 is
linked into the toolchain; no separate LLVM installation is needed.

After publication, install with an existing `rockup`:

```sh
rockup self update
rockup install v0.7.3
rockup default v0.7.3
rock --version
```

For a fresh installation, use the pinned bootstrap after publication:

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/Rock-lang-org/Rock/releases/download/v0.7.3/install.sh | sh -s -- v0.7.3
```
