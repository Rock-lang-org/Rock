# Rock v0.7.0

Rock v0.7.0 brings Unicode-aware strings, generalized iteration, default generic type arguments, explicit integer arithmetic policies, and a reorganized standard library named `std`.

## Changelog

### Language and Standard Library

- **UTF-8 strings:** `Char` is a 32-bit Unicode scalar value. Strings support validated byte conversion with `String::from_utf8`, checked byte-range slicing at UTF-8 boundaries, scalar lookup, and borrowing `chars!` and `char_indices!` cursors. String lengths and search offsets still count bytes; embedded NUL bytes are preserved by Rock string operations.
- **Generalized iteration:** `for..in` and `for_each` use short-circuiting `Foldable` and `FoldableValue` protocols, including custom foldable types and character cursors. `break` stops traversal immediately.
- **Default generic types:** structs, enums, traits, and type aliases accept defaults such as `struct Pair A, {B = A}`. Defaults resolve in declaration scope, may refer to earlier parameters, and are applied only after ordinary construction inference has had its chance.
- **Equality and ordering:** `PartialEq {Rhs = Self}` supports same-type and directional cross-type equality, including `String`/`&Str` comparisons. `PartialOrd`, `Eq`, and `Ord` distinguish partial from total comparison; floating-point comparisons preserve NaN behavior.
- **Explicit integer arithmetic:** the `Integer` trait supplies `checked_*`, `wrapping_*`, `saturating_*`, and `overflowing_*` operations. Ordinary integer arithmetic uses the policy compiled into its std implementation: checked in debug builds and wrapping in release builds. Division by zero and signed minimum divided or remaindered by `-1` always fail.
- **Library-owned primitives:** arithmetic, comparisons, indexing, pointer access, and sequence helpers are implemented through explicit intrinsics in std rather than compiler fallbacks. Arrays and slices expose `len!`, `is_empty!`, `as_ptr!`, and `as_mut_ptr!`; memory helpers include `sizeof` and `sizeof_pointee`.
- **Organized `std` modules:** public APIs are grouped under `std::mem`, `std::cmp`, `std::num`, `std::ops`, `std::functional`, `std::collections`, `std::string`, `std::control`, `std::io`, `std::concurrency`, and `std::ffi`, with the everyday vocabulary available through the prelude.

```rock
struct Pair A, {B = A}
    < first: A
    < second: B

main = !->
    pair: Pair I64 = Pair
        first: 20
        second: 22
    (pair.first + pair.second).println!
    for ch in "Rock 🦀".chars!
        ch.println!
```

This prints `42`, followed by each Unicode scalar in `Rock 🦀` on its own line.

### Tooling

- **Build profiles:** `rock build`, `rock run`, `rock artifact`, and `rockc` accept `--debug` and `--release` instead of `-O`. Project outputs and dependency caches are separated into `build/debug/` and `build/release/`.
- **Project cleanup:** `rock clean` removes the current project's build output and dependency cache without touching source files or the installed std.
- **Build feedback:** live progress reports compilation work and cache reuse.
- **Compiler control:** `rockc --overflow-checks true|false` selects integer overflow policy independently of optimization when building source; it does not change a prebuilt dependency's policy.
- **Documentation:** refreshed README and book examples cover Unicode strings, iteration, generic defaults, standard-library modules, and the current project workflow.

### Fixes

- Fixed optimized unit-returning `main` functions so successful effect-only programs return exit status zero.
- Corrected loan tracking through aggregate returns, mixed explicit and tail returns, and raw-pointer returns and reborrows, including calls through prebuilt dependency artifacts.
- Fixed mutually recursive and cross-module generic defaults, declaration-order handling, and static-method default instantiation.
- Improved constant integer arithmetic diagnostics and transitive arithmetic summaries carried by dependency artifacts.
- Improved compilation and regression-test performance, and fixed a concurrent release-test panic.

## Migration from v0.6.0

- Replace `stdlib::...` imports with the corresponding `std::...` paths and update old flat modules to the new public facades, for example `std::collections::Vec`, `std::mem::Box`, `std::io::fs::File`, and `std::io::net::TcpStream`. Old crate and module names are not retained as aliases.
- Source-build and artifact workflows now use `std/`, `std.rkca`, `std.o`, `--extern-artifact std=...`, and `rockup dev std package`.
- Replace `-O` options with `--debug` or `--release`; update scripts that read the former unprofiled build paths.
- Custom foldable implementations must provide the new short-circuiting `try_fold` contract; `foldl` has a default implementation.
- Use `PartialEq` and `PartialOrd` for partial comparisons, particularly floats; implement `Eq` or `Ord` only when their stronger promises hold.
- Review FFI and raw-storage assumptions about `Char`: it now represents a 32-bit Unicode scalar rather than a byte. Use `U8` for raw bytes, and validate untrusted UTF-8 with `String::from_utf8`.
- Rebuild all dependency artifacts with the matching 0.7.0 compiler and std. Artifact format 50 is not compatible with earlier formats; keep compiler binaries, std, objects, artifacts, and component metadata from the same build.
- A precompiled std keeps its producer's overflow policy even when an application changes build profiles. Rebuild std to select a different ordinary-arithmetic policy, or use explicit `Integer` methods for profile-independent behavior.

## Install or Update

Linux x86_64 GNU only. Requires glibc 2.39 or newer, a C linker, curl, CA certificates, GNU tar, gzip, and `sha256sum`. On Ubuntu 24.04, install `build-essential curl ca-certificates`. LLVM 18 is statically linked; an LLVM installation is not required. The executables are not fully static.

Install the pinned release after publication:

```sh
curl --proto '=https' -fsSL https://github.com/Rock-lang-org/Rock/releases/download/v0.7.0/install.sh | sh -s -- v0.7.0
```

With an existing manager:

```sh
rockup self update
rockup install v0.7.0
rockup default v0.7.0
rock --version
```

Managers older than v0.5.2 may require the [repository-transfer recovery procedure](https://github.com/Rock-lang-org/Rock/blob/v0.7.0/docs/releases.md#repository-transfer).

Rock remains experimental: syntax, APIs, tooling, and artifact formats can change. Unicode APIs operate on scalars and byte boundaries, not grapheme clusters. This release does not add Windows or macOS toolchains.
