# Rock v0.7.4

Rock v0.7.4 adds compound assignment and fold operators, smoother multiline
pipelines, and a substantially faster compiler.

## Highlights

- **Compound assignment.** The standard library defines `+=`, `-=`, `*=`,
  `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, and `>>=` for the numeric and boolean
  types. They are ordinary operators backed by traits in `std::ops`, such as
  `AddAssign`, so your own types can implement them. They work on indexed
  places too: `values[i] += 1` evaluates the index once.
- **Folds.** `RightFoldable` and `foldr` traverse `Vec`, `Option`, `Result`,
  and bounded ranges from the right. The `<&<` and `>&>` operators fold a
  container left or right with a `(step, initial)` pair.
- **Pipelines.** A multiline expression can alternate operator stages and
  method stages, for example `<&> normalize` followed by `.foldl step, 0`.
- **Compiler speed.** The compiler itself is built for speed. Small programs
  no longer pay for the parts of std they do not use. Inference, coherence
  checking, and monomorphization do less redundant work on large crates.
  `rock build` skips revalidating dependency artifacts that did not change.
- **Standard library builds.** Std is always built optimized with overflow
  checks enabled, including when a package depends on std by path.
- **Inference.** A function without a type signature can now read fields of a
  struct imported from another crate, for example a request handler passed to
  a library's `serve` method.

## Upgrading from v0.7.3

- Monadic bind is now `>>-`. `>>=` means right-shift assignment. Replace
  `value >>= next` with `value >>- next`; `bind` and `do` are unchanged.
- `^` can now start or continue an operator, so `^=` and `^+` are single
  operator tokens. Mutable borrows such as `&^value` and `&^*ptr` are
  unchanged.
- Rebuild `.rkca` dependencies with the new compiler and its matching
  standard library.

## Install or update

The packaged toolchain targets Linux x86-64 GNU and requires glibc 2.39 or
newer, a C linker, curl, CA certificates, GNU tar, gzip, and `sha256sum`.
On Ubuntu 24.04, install `build-essential curl ca-certificates`. LLVM 18 is
linked into the toolchain; no separate LLVM installation is needed.

After publication, install with an existing `rockup`:

```sh
rockup self update
rockup install v0.7.4
rockup default v0.7.4
rock --version
```

For a fresh installation, use the pinned bootstrap after publication:

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/Rock-lang-org/Rock/releases/download/v0.7.4/install.sh | sh -s -- v0.7.4
```
