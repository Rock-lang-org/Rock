# Rock v0.7.1

Rock v0.7.1 adds array-length const generics, expression and cross-crate macros,
importable enum constructors, and library/multiple-binary packages. It improves
closure ownership, inference, cleanup, and diagnostics. Rock remains experimental:
this patch version does not imply source or artifact compatibility with v0.7.0.

## Changelog

### Added

- **Package targets:** one `[lib]` and multiple `[[bin]]` targets can coexist.
  `rock build` builds all targets; `rock run --bin NAME` selects a binary.
  Library-only packages build without inventing an executable entry point.
- **Build output:** `rock build` reports all target products. `rock --quiet`
  (`-q`) suppresses output from invoked compiler tools while retaining failure
  output.
- **Declarative macros:** expansion runs in every loaded module and in
  expression position. Exported macros travel through dependency artifacts and
  explicit imports, with identity keyed by originating crate. Repetitions close
  with `)*` and support inline copies, repeated lines, and direct captures in
  repeated templates.
- **Formatting:** the std prelude exports `%format` and `%println`. Primitive
  `Show` implementations cover signed and unsigned integer widths, both float
  widths, `Bool`, `Char`, `&Str`, and unit. `String::from` accepts `U64`, with
  full-range signed and unsigned decimal formatting.
- **Enum imports:** variants support imports, re-exports, short-name
  construction and matching, and dependency-artifact transport. The std prelude
  imports `Some`, `None`, `Ok`, and `Err`.
- **Const generics:** `usize` parameters describe array lengths in structs,
  enums, traits, aliases, functions, and implementations. Lengths infer through
  nested arrays and work in repeat literals such as `[0; N]`.
- **Arrays and vectors:** nested fixed arrays support chained indexing. Owned
  array loops move elements and clean up unvisited elements on early exits.
  `Vec::from` and `.into!` convert fixed arrays to vectors across lengths;
  byte vectors provide `extend_from_slice`.
- **File reads:** `std::io::fs::read_to_string` reads through EOF, handles short
  and interrupted reads, preserves embedded NUL bytes in contents, and rejects
  invalid UTF-8. `IoError` display includes its variant and OS error number;
  `ThreadError` implements `Show`.

### Changed and Fixed

- Closure ownership follows capture liveness: last-use captures can move into
  escaping closures; body effects determine `Fn`, `FnMut`, or `FnOnce`.
  Owned captures are destroyed even when a closure is never called, including
  environments stored behind erased function types.
- Detached thread closures require the std-owned capture marker alongside
  callable and thread-safety contracts. Last local use does not make a borrowed
  capture safe to detach.
- Improved inference of returned numeric literals from caller context, local
  `_` annotation holes, bound-only generic parameters, by-value generic
  receivers, and recursive trait-bound propagation.
- Imports resolve against declared names, including later declarations and
  signature-only items. Unresolved imports are errors. Explicit imports shadow
  glob bindings; local bindings shadow top-level items instead of reassigning
  them. Modules cannot reuse a dependency's name.
- Duplicate operator declarations are errors, including across dependencies.
  Unknown annotation types, undeclared field types, unresolved struct literals,
  kind mismatches, and invalid instantiated array lengths receive diagnostics
  instead of permissive fallbacks or panics.
- Improved move diagnostics, transactional pattern matching, loop cleanup,
  closure drops, and array-length validation and artifact decoding.

### Compiler and Documentation Maintenance

- Split large compiler modules and integration suites into focused modules;
  moved test-only code out of production files and removed source-text audits.
- Consolidated ownership of collection, lowering, MIR/drop, closure, codegen
  layout, and callable-symbol state; removed obsolete fallback paths.
- Updated the book, READMEs, and language reference. Documentation checks now
  include the root README's Rock examples, std README, language reference, and
  companion libraries for package and macro examples.
- Updated release smoke projects to use binary targets and unit-returning main
  functions.

## Migration from v0.7.0

- Application manifests using `[lib]` for an executable must use `[[bin]]`;
  reserve `[lib]` for a library entry point. Packages with several binaries
  select one with `rock run --bin NAME`.
- Replace `rock artifact` with `rock build` for library packages; library
  artifacts are now ordinary build products, not a separate subcommand.
- Close macro repetitions with `)*`, not a bare `)`. Explicitly import exported
  macros; glob imports do not bring macros into scope.
- Fix unresolved imports, duplicate operator declarations, dependency/module
  name collisions, and undeclared types rather than relying on old acceptance.
- Exporting an enum does not introduce its variants as short names in consumers;
  import the variant or use `Enum::Variant`.
- Rebuild all dependency artifacts and std with the matching v0.7.1 compiler.
  Keep compiler binaries, std, object files, artifacts, and component metadata
  from the same build; do not mix v0.7.0 artifacts with this release.
- Error display strings are more specific. Do not depend on the old generic
  `IoError` label when reporting failures.

## Install or Update

Linux x86_64 GNU only. Requires glibc 2.39 or newer, a C linker, curl, CA
certificates, GNU tar, gzip, and `sha256sum`. On Ubuntu 24.04, install
`build-essential curl ca-certificates`. LLVM 18 is statically linked; end users
do not need an LLVM installation. The executables are not fully static.

After publication, install the pinned release:

```sh
curl --proto '=https' -fsSL https://github.com/Rock-lang-org/Rock/releases/download/v0.7.1/install.sh | sh -s -- v0.7.1
```

With an existing manager:

```sh
rockup self update
rockup install v0.7.1
rockup default v0.7.1
rock --version
```

Managers older than v0.5.2 may require the
[repository-transfer recovery procedure](https://github.com/Rock-lang-org/Rock/blob/v0.7.1/docs/releases.md#repository-transfer).

Syntax, APIs, tooling, and artifact formats remain experimental. Nested macro
repetition remains unsupported; see the book's known limitations. This release
does not add Windows or macOS toolchains.
