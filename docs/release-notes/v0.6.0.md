# Rock v0.6.0

Rock v0.6.0 adds flat monadic sequencing, expands the functional standard-library APIs, and makes call-result propagation and multiline method chains consistent.

## Highlights

- **`do` notation:** sequence `Option`, `Result`, and custom carriers using `<-`, ordinary assignments, and a final expression. The parser expands the block into calls to the `bind` function in scope.
- **Consistent call boundaries:** multiline method chains continue the completed call, and postfix `?` propagates a call's result before following operators, methods, indices, casts, or further calls. Explicitly grouped arguments retain their own propagation.
- **Unified conversions:** `From` implementations replace the specialized safe `String::from_*` constructors; `Into` provides the corresponding conversions for callers.
- **Functional APIs:** expanded callable-trait dispatch, standalone and receiver-based higher-kinded APIs, generic `for_each`, and unit-returning function shorthand such as `(!.println!)`.
- **Project creation:** `rock new` creates a new application project.
- **Compiler fixes:** corrected transitive closure captures, restoration of shadowed bindings, and indentation after multiline call chains.
- **Documentation and tooling:** practical functional examples, a README `do` showcase, and a pinned tree-sitter grammar with `do` syntax, highlighting, and scope support. Editor integrations and `rock_http` are maintained in separate repositories.

```rock
main = !->
    result = do
        first <- Option::Some 20
        second <- Option::Some 22
        pure first + second
    result.unwrap_or 0 .println!
```

This prints `42`; a `None` at either bind skips the remaining continuation.

## Migration from v0.5.2

- Replace `String::from_str text`, `String::from_bytes bytes`, and `String::from_i64 number` with `String::from text`, `String::from bytes`, and `String::from number` respectively.
- `do` is now a reserved keyword.
- An ungrouped call's `?` now consistently belongs to the call result. When an argument needs its own propagation, place `?` inside that argument's parentheses, particularly before another comma-separated argument.
- Rebuild application dependencies with the matching compiler and standard library; keep the distributed compiler, objects, artifacts, and component metadata together.
- The book's HTTP tutorial pins an updated `rock_http` revision compatible with the conversion API. Update older checkouts before using them with v0.6.0.

## Install or Update

Linux x86_64 GNU only. Requires glibc 2.39 or newer, a C linker, curl, CA certificates, GNU tar, gzip, and `sha256sum`. On Ubuntu 24.04, install `build-essential curl ca-certificates`. LLVM 18 is statically linked; an LLVM installation is not required. The executables are not fully static.

Install the pinned release:

```sh
curl --proto '=https' -fsSL https://github.com/Rock-lang-org/Rock/releases/download/v0.6.0/install.sh | sh -s -- v0.6.0
```

With an existing manager:

```sh
rockup self update
rockup install v0.6.0
rockup default v0.6.0
rock --version
```

Managers older than v0.5.2 may require the [repository-transfer recovery procedure](https://github.com/Rock-lang-org/Rock/blob/v0.6.0/docs/releases.md#repository-transfer).

Rock remains experimental: syntax, APIs, tooling, and artifact formats can change. The standard monadic `bind` retains its `FnMut` callback contract and the compiler's existing ownership checks.

**Full changelog:** https://github.com/Rock-lang-org/Rock/compare/v0.5.2...v0.6.0
